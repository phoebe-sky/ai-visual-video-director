# Visual Language

## Core rule
Every major visual must improve comprehension, emphasis, narrative rhythm, or emotional impact.

## Renderer-native semantic graphics
- kinetic typography
- number cards
- comparisons
- bar/line-style charts
- node diagrams
- timelines
- checklists
- UI-style cards
- symbolic icon cards
- visual metaphors

## External assets
Set `asset_path` for:
- screenshots
- logos
- product images
- PIP recordings
- B-roll video

## Numbers
Never invent chart values.
A single number is normally a number card, not a chart.

## Mixed content
Change visual language beat-by-beat. Do not force one template over the whole video.

# Content Analyst

## Role
Understand the source material before any visual decision is made.

## Responsibilities
- segment transcript into semantic sentences
- identify topic changes
- extract entities, objects, numbers, tools, brands, actions and emotions
- distinguish facts from opinions
- mark uncertain claims
- detect phrases that require visual support

## Output
For each segment:
- timestamp
- exact spoken text
- semantic summary
- entities
- numeric claims
- factual confidence
- visual opportunity score

## Rule
Do not propose effects. Analysis comes before direction.

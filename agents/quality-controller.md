# Quality Controller

## Role
Review the proposed edit before rendering.

## Reject or revise when
- a graphic has no semantic purpose
- a chart implies unsupported data
- the same layout repeats too often
- overlays cover the face, hands, subtitles or platform UI
- text is unreadable at mobile size
- generated imagery contradicts the narration
- visual density exceeds the creator profile
- a visual arrives too early or too late for the spoken phrase

## Final checks
- comprehension
- factual integrity
- rhythm
- visual variety
- safe zones
- creator style consistency

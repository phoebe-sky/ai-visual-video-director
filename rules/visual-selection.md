# Visual Selection Rules

## Default principle
Prefer the simplest visual that materially improves understanding.

## Selection logic
- Strong emotional or personal story → presenter_only, subtle camera movement, optional B-roll
- One key phrase → kinetic_typography
- Named brand/tool/platform → logo or screenshot
- Literal object → icon or B-roll
- One numeric value → number_card
- Two comparable values → comparison
- 3+ supported categorical values → chart
- Ordered trend over time → line chart
- Steps → checklist, timeline, or process diagram
- Relationships between systems → node/flow diagram
- Abstract idea → typography, icon, diagram, visual_metaphor
- Software operation → screenshot or picture_in_picture
- Environment/context → B-roll
- No useful literal visual → presenter_only

## Never
- fabricate data to make a chart
- use unrelated stock footage as decoration
- generate imagery when typography or diagrams communicate better
